Security controls in this build
  • Content Security Policy allows only this page and one outbound host (formsubmit.co); no external scripts, fonts or images.
  • Every user-typed value is escaped before it is rendered, and control and bidirectional characters are stripped on input.
  • Fields are length-limited and checked against fixed lists; ids must match the task id format.
  • The notification endpoint is checked as HTTPS on formsubmit.co before any request is sent; no cookies or referrer are included.
  • A hidden honeypot field and a limit of 5 new tasks per minute slow down automated submissions; the board holds at most 200 tasks.
  • No browser storage is used. Do not enter real customer or bank data; this is a demo.
